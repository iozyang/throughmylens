# Design system

The public site will use an editorial-gallery system rather than a dashboard component library. Phase 1 establishes only the shared base tokens in `apps/web/app/globals.css`:

- warm neutral surface, near-black ink and restrained rules;
- editorial serif direction for work and project titles;
- readable neutral sans-serif for interface, body text and metadata;
- no rounded-card defaults, promotional gradients or decorative motion.

Phase 4 will add calibrated typography, image frames, spacing scales, breakpoints, lightbox behavior and motion tokens after review against real photographs in both Chinese and English.
