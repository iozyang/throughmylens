- 高质量图片升级的可见范围判断改用目标布局的 offsetTop / offsetHeight，不读取仍处于 FLIP 动画中的旧视觉位置。相册网格建立定位上下文，避免扩大档位时把大量已经远离视口的照片误判为可见。
