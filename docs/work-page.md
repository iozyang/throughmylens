# 作品页

地址：<http://localhost:3000/zh/work>；英文版：<http://localhost:3000/en/work>。

首页“浏览作品”和顶栏“作品”直接进入此页；语言切换保留 `/work` 路径，品牌链接返回首页。

## 范围和设计

- 完整展示 `selected-work.json` 中的现有照片，与首页共享信息和排序，未复制一份编辑数据。完整资料只在服务端读取，浏览器仅接收展示字段；地点取 `location.display`，GPS 和详细定位文本不会被下发。
- 静态纵向画廊，不自动移动，不复制轮播缓冲。每行最多三张，照片按自然比例分配宽度、等高排列；宽高比至少 2.2 的全景独占一行，单独的竖幅限制宽度并居中。
- 保留现有暖白底色、克制标题和留白，不增加大标题首屏、分类、搜索、筛选、登录或下载入口。
- 悬停地点、时间、参数依次渐显（200/400/600ms），移开同步 300ms 渐隐。参数仅焦距、光圈、快门、ISO，以空格分隔。
- 点击或键盘 Enter 进入现有全屏查看器；Escape、关闭按钮或背景关闭，回到原位置及原照片焦点。
- 图片懒加载，按行内占比请求展示尺寸，大图仍按需加载；不裁切原片。
- 移动端先采用单列自然比例，沿用轻触信息、长按大图的基础交互，不开展深度移动端优化。

缺失元数据继续使用待补充提示。本轮不补写照片事实、不改动原图或编辑 JSON，也不触碰后台草稿库。页面暂保留 `noindex`，继续 localhost 开发。
